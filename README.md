## 📖 Full Description

**Firecracker** is a versatile Python-based script engineered for efficiency and cross-platform compatibility. Because it is written in pure Python, it bypasses the heavy constraints of operating-system-specific binaries, allowing you to run, test, and execute your code anywhere—whether you are working from a Windows desktop, a Linux distribution, or directly on your mobile device via a terminal environment. 

This repository contains the core source code along with instructions on how to set it up, test it, and run it across your entire ecosystem without requiring expensive hardware or complex build chains.

---

## 🚀 How It Works

* **Core Logic:** Written entirely in clean Python (`firecracker.py`).
* **Windows (`.exe` / Script):** Runs via the standard Python interpreter or can be packaged locally using PyInstaller.
* **Linux (The Penguin):** Executes natively using the built-in Python 3 environment.
* **Android (Mobile Execution):** Runs directly inside mobile terminal emulators like **Termux**, allowing full script execution on mobile hardware.

## 📥 Installation & Usage Guide

### 📱 Android (Using Termux)
If you are testing or running this on an Android phone without a PC:
# 1. Open Termux and install Python and Git:
   bash:
   ```pkg update && pkg install python git ```
#   Clone this repository to your phone:
   ```git clone [https://github.com/samarthhegde97/Firecracker.git](https://github.com/samarthhegde97/Firecracker.git)```
#   Move into the project folder
   ```cd Firecracker```
#   Run the script:
   ```python firecracker.py```

# 🪟 Run on Windows:
Download or clone this repository to your PC.

Ensure you have Python installed and added to your system PATH.

Open Command Prompt (cmd) or PowerShell in the folder where firecracker.py is saved.

Run the application: from releases

# 🐧 Linux (The Penguin)
Open your Linux terminal.

# Clone or download the repository:
```git clone [https://github.com/samarthhegde97/Firecracker.git](https://github.com/samarthhegde97/Firecracker.git)```
# Navigate to the folder and make the script executable:
``` cd Firecracker ```
```chmod +x firecracker.py```
# Run it using Python 3:
```python3 firecracker.py```
